# Lesson 1.1: The Opening Ping-Pong

**Target:** Hello / Hi / Hey, How are you?, I'm fine / good / great / cool, thank you, What about you?
**Duration:** ~3 minutes (10 screens)

---

## Screen 1: Word Anchors (Greetings)
**Type:** Input / Lexicon Intro

**UI Elements:**
- 3 stacked word cards: Hello, Hi, Hey
- Transliteration & Meaning badges:
  - Hello → هێڵۆو / (سڵاو)
  - Hi → های / (سڵاو)
  - Hey → هێی / (سڵاو - نافەرمی)

**Audio & Logic:** Tapping any card plays clear native pronunciation. User must tap all 3 cards to enable the Continue button.

---

## Screen 2: Acoustic Match (Sound to Spelling)
**Type:** Ear Verification / Matching

**UI Elements:**
- Left Column: 3 playable audio buttons: [ ▶ Sound 1 ], [ ▶ Sound 2 ], [ ▶ Sound 3 ] (randomized order: Hi, Hey, Hello)
- Right Column: 3 English text tiles: [ Hey ], [ Hello ], [ Hi ]. Zero Kurdish text.

**Audio & Logic:** User plays an audio clip, then taps the matching English word tile. Correct pair highlights green and locks; mismatch triggers vibration and resets the selection.

---

## Screen 3: The "How are you?" Deconstruction
**Type:** Analytic Breakdown / Multi-Row List

**UI Elements:**
- 4 interactive horizontal rows:
  - Row 1: How | [ ▶ ] | هەو | (چۆن)
  - Row 2: are | [ ▶ ] | ئاڕ | (هەیت)
  - Row 3: you | [ ▶ ] | یو | (تۆ)
  - Row 4 (Accent Border): How are you? | [ ▶ ] | هەواریو؟ | (چۆنیت؟)

**Audio & Logic:** Tapping rows 1–3 plays individual word audio. Tapping Row 4 plays connected native speech. User must play Row 4 to unlock the next screen.

---

## Screen 4: The Echo Mic (Spoken Practice)
**Type:** Oral Production / Rehearsal

**UI Elements:**
- Large prompt: How are you?
- Sub-text guide: هەواریو؟
- Center: Large pulsating microphone button

**Audio & Logic:** Screen auto-plays native audio model once. User taps the mic and speaks "How are you?". System performs acoustic validation (untimed, 2 retry attempts allowed on fail).

---

## Screen 5: Status Adjectives Bank
**Type:** Input / Lexicon Expansion

**UI Elements:**
- Header frame: I'm [ ___ ], thank you.
- 4 selectable status cards:
  - fine (فاین / باش)
  - good (گود / باش)
  - great (گرەیت / زۆر باش)
  - cool (کووڵ / نایاب)

**Audio & Logic:** Tapping a card inserts the word into the frame and plays the full sentence audio. Learner must tap all 4 to enable Continue.

---

## Screen 6: Slot-and-Filler Check
**Type:** Syntax & Role Discrimination

**UI Elements:**
- Target sentence: I'm [ ? ], thank you.
- 4 multiple-choice options: [ great ], [ hello ], [ how ], [ are ]

**Audio & Logic:** User taps great to complete the sentence. Incorrect tiles shake red; correct tile snaps into place and auto-plays full audio: "I'm great, thank you."

---

## Screen 7: Conversational Response Pairing
**Type:** Social Logic Match

**UI Elements:**
- Left: [ Hi Sara ], [ How are you? ]
- Right: [ I'm good, thank you ], [ Hello Ahmad ]

**Audio & Logic:** User connects each prompt to its natural response. Connecting Hi Sara to I'm good, thank you fails. Forces distinction between greeting someone and reporting condition.

---

## Screen 8: The Bounce-Back Anchor ("What about you?")
**Type:** Core Idiom / Pragmatic Isolation

**UI Elements:**
- Large card: What about you?
- Pronunciation helper: وەرەباوتیو؟
- Meaning: (ئەی تۆ؟ / تۆ چۆنیت؟)
- Functional role choice:
  - [ Ask the question back ] (Correct)
  - [ Say goodbye ] (Distractor)

**Audio & Logic:** Audio plays native reduction (/wʌt əbaʊt juː/). User taps the correct communicative function to advance.

---

## Screen 9: Interactive Chat Dialogue
**Type:** Simulation / Contextual Assembly

**UI Elements:**
- Bubble 1 (Incoming): "Hey Ahmad, how are you?" (Audio auto-plays)
- Bubble 2 (Draft area): Blank with 3 response choices:
  - A: I'm cool, thank you. What about you? (Correct)
  - B: I'm fine, thank you. Hi Sara.
  - C: Hello, me too.

**Audio & Logic:** User selects Option A. Bubble 2 populates and full audio plays.

---

## Screen 10: Capstone Spoken Handshake
**Type:** Timed Forced Production (Lesson Gate)

**UI Elements:**
- Avatar waves; speech bubble plays: "Hey, how are you?"
- Prompt banner: Respond and ask them back!
- Visual scaffold: I'm [good / cool], thank you. What about you?
- Active mic button with 4-second circular countdown timer

**Audio & Logic:** Cold mic. User must speak the full response before the timer expires. Passes ≥75% acoustic match to unlock Lesson 1.2 and award XP.
